# a11y - Accessibility

WCAG (Web Content Accessibility Guidelines) accessibility tools. Determine the readability of text against background colors, and find the best choice among multiple candidate colors.

## Install

```ts
import xcolor from '@xpyjs/color'
import a11yPlugin from '@xpyjs/color/plugins/a11y'

xcolor.use(a11yPlugin)
```

## Methods

### isReadable(other, options?)

Determine whether the combination of the current color and another color meets WCAG readability standards.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `other` | `XColorInput` | — | Target color to compare |
| `options.level` | `'AA' \| 'AAA'` | `'AA'` | WCAG level |
| `options.size` | `'normal' \| 'large'` | `'normal'` | Text size |

**Return value**: `boolean`

```ts
xcolor('#000000').isReadable('#ffffff')                     // true (contrast ratio 21:1)
xcolor('#000000').isReadable('#ffffff', { level: 'AAA' })   // true
xcolor('#888888').isReadable('#ffffff')                     // false (normal text contrast too low)
xcolor('#888888').isReadable('#ffffff', { size: 'large' })  // true (lower large-text threshold)
```

### mostReadable(candidates, options?)

Find the color with the highest contrast ratio against the current color from a list of candidate colors; falls back to black or white if none meets the threshold.

| Parameter | Type | Description |
| --- | --- | --- |
| `candidates` | `XColorInput[]` | List of candidate colors |
| `options.level` | `'AA' \| 'AAA'` | WCAG level, default `'AA'` |
| `options.size` | `'normal' \| 'large'` | Text size, default `'normal'` |

**Return value**: `XColor`

```ts
xcolor('#333333').mostReadable(['#ffffff', '#eeeeee', '#cccccc']).toHex()
// '#ffffff' — highest contrast ratio
```

### wcagLevel(other)

Return the WCAG levels met by the two colors for normal and large text.

| Parameter | Type | Description |
| --- | --- | --- |
| `other` | `XColorInput` | Target color to compare |

**Return value**: `{ level, largeText, ratio }`, where each level is `'AAA' | 'AA' | 'FAIL'`.

```ts
xcolor('#000000').wcagLevel('#ffffff')
// { level: 'AAA', largeText: 'AAA', ratio: 21 }
xcolor('#666666').wcagLevel('#999999')
// { level: 'FAIL', largeText: 'FAIL', ratio: 2.02 }
```

## Practical Scenarios

### Ensure Text Readability

```ts
const bg = xcolor('#1a1a2e')
const textColor = bg.mostReadable(['#ffffff', '#e0e0e0', '#a0a0a0'])
// Automatically selects the text color with the best contrast ratio
```

### Validate Design Mockups

```ts
const pairs = [
  ['#333', '#fff'],
  ['#666', '#eee'],
  ['#999', '#ccc']
]

pairs.forEach(([text, bg]) => {
  const readable = xcolor(text).isReadable(bg)
  const level = xcolor(text).wcagLevel(bg)
  console.log(`${text} on ${bg}: ${readable ? '✓' : '✗'} (${level})`)
})
```
