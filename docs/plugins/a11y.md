# a11y - 无障碍

WCAG (Web Content Accessibility Guidelines) 无障碍工具。判断文本与背景色的可读性，并在多个候选色中找到最佳选择。

## 安装

```ts
import xcolor from '@xpyjs/color'
import a11yPlugin from '@xpyjs/color/plugins/a11y'

xcolor.use(a11yPlugin)
```

## 方法

### isReadable(other, options?)

判断当前颜色与另一个颜色的组合是否满足 WCAG 可读性标准。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `other` | `XColorInput` | — | 比较目标颜色 |
| `options.level` | `'AA' \| 'AAA'` | `'AA'` | WCAG 等级 |
| `options.size` | `'normal' \| 'large'` | `'normal'` | 文本尺寸 |

**返回值**：`boolean`

```ts
xcolor('#000000').isReadable('#ffffff')                          // true（对比度 21:1）
xcolor('#000000').isReadable('#ffffff', { level: 'AAA' })        // true
xcolor('#888888').isReadable('#ffffff')                          // false（正文对比度不足）
xcolor('#888888').isReadable('#ffffff', { size: 'large' })       // true（大字阈值较低）
```

### mostReadable(candidates, options?)

在候选颜色列表中，找到与当前颜色对比度最高的颜色；若均未达到阈值，则回退到黑色或白色。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `candidates` | `XColorInput[]` | 候选颜色列表 |
| `options.level` | `'AA' \| 'AAA'` | WCAG 等级，默认 `'AA'` |
| `options.size` | `'normal' \| 'large'` | 文本尺寸，默认 `'normal'` |

**返回值**：`XColor`

```ts
xcolor('#333333').mostReadable(['#ffffff', '#eeeeee', '#cccccc']).toHex()
// '#ffffff' — 对比度最高
```

### wcagLevel(other)

返回两个颜色在正文和大字场景下分别满足的 WCAG 等级。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `other` | `XColorInput` | 比较目标颜色 |

**返回值**：`{ level, largeText, ratio }`，其中等级为 `'AAA' | 'AA' | 'FAIL'`。

```ts
xcolor('#000000').wcagLevel('#ffffff')
// { level: 'AAA', largeText: 'AAA', ratio: 21 }
xcolor('#666666').wcagLevel('#999999')
// { level: 'FAIL', largeText: 'FAIL', ratio: 2.02 }
```

## 实际场景

### 确保文本可读

```ts
const bg = xcolor('#1a1a2e')
const textColor = bg.mostReadable(['#ffffff', '#e0e0e0', '#a0a0a0'])
// 自动选择对比度最佳的文本颜色
```

### 检查设计稿

```ts
const pairs = [
  ['#333', '#fff'],
  ['#666', '#eee'],
  ['#999', '#ccc']
]

pairs.forEach(([text, bg]) => {
  const readable = xcolor(text).isReadable(bg)
  const level = xcolor(text).wcagLevel(bg)
  console.log(`${text} on ${bg}: ${readable ? '✓' : '✗'} (${level})`)
})
```

## 无效颜色与半透明颜色

`isReadable()` 遇到无效颜色返回 `false`。`wcagLevel()` 遇到无效颜色会抛错。`mostReadable()` 会跳过无效候选，基色无效时抛错。核心 `contrast()` 仍返回数值，解析失败时也会使用回退通道计算。

```ts
import xcolor from '@xpyjs/color'
import blend from '@xpyjs/color/plugins/blend'
import a11y from '@xpyjs/color/plugins/a11y'

xcolor.use(blend).use(a11y)
const background = xcolor('#fff').blend('rgb(0 0 255 / 20%)', 'normal')
const foreground = background.blend('rgb(0 0 0 / 80%)', 'normal')
foreground.isReadable(background)
```

先把背景合成到不透明底色，再把文字合成到所得背景。用合成后的文字颜色和背景颜色检查对比度。
